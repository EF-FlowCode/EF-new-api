# 聊天客户端预设

聊天入口会使用站点地址与用户选择的 API Key 展开预设链接。2026-10-04 工作区新增 AQBot 预设：

```text
aqbot://providers?{aqbotConfig}
```

该链接展开为 name（New API）、baseurl（站点地址）、apikey（所选密钥）、type（openai）四个查询字段，每个值分别 URL 编码，避免密钥或地址中的 `&`、`+`、`#` 等字符被误当成分隔符。AQBot 入口会先要求选择密钥；链接由已安装的 AQBot 客户端处理。

默认列表只用于未保存自定义 Chats 的环境。已经保存的聊天预设不会被新默认项覆盖；管理员需要在聊天预设中自行添加上述条目。此增量尚未发布，已验证链接生成、密钥判断、类型和局部 lint；未实测外部 AQBot 客户端的导入流程。
