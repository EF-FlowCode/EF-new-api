# 额度与推荐奖励设置

> 定位：现行使用与配置指南。带日期的部署或验证段落保留为当时记录；分类入口见[文档导航](../README.md)。

管理员从“财务设置 → 额度设置”维护新用户额度、预消费额度、推荐奖励和外部入口。

`AffiliateEnabled` 是推荐计划总开关：

- 开启后，用户端显示推荐入口；只有邀请人存在且已确认支付合规（`IsPaymentComplianceConfirmed`）时，才按 `QuotaForInviter`、`QuotaForInvitee` 发放新奖励。
- 关闭后，用户端隐藏推荐入口，同时停止发放后续邀请奖励。
- 关闭不会删除历史奖励，也不会回收已经到账的额度。

配置继续保存在现有 `options` 表中，不需要数据库迁移。

历史异常消费的站内余额返还，见 [消费余额批量返还](batch-usage-refund.md)。该功能支持日志页和命令行预览、批量执行，并生成用户可见返还日志。

## 2026-10-04 额度边界修正（工作区，未发布）

兑换码创建/修改要求额度大于 0 且小于 `MaxQuota`（2147483647）。兑换后的钱包最多为 `MaxQuota−1`，容量不足、无效旧额度或用户不存在时，余额和兑换码状态一起回滚，兑换码不会被消耗。该上限沿用当前充值合同，本轮没有扩容钱包。

直接增减用户额度时，先完成数据库写入再更新缓存；数据库失败不会提前改变缓存。批量模式仍沿用既有异步合同。工具附加费和渠道测试计费补充安全限幅，极端数值不应在转换整数时绕回负数。普通价格、分组、舍入以及 USD/CNY 显示不受本轮修正影响。
