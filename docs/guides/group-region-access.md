# 网页分组地区访问控制

> 定位：现行使用与配置指南。带日期的部署或验证段落保留为当时记录；分类入口见[文档导航](../README.md)。

该功能只控制网页中的分组选择器、API 密钥列表提示和模型广场展示，不改变 API 转发、Access Token 或其他服务端 API 的分组权限。

## 地区识别

项目读取 Cloudflare 注入的 `CF-IPCountry` 请求头，并使用 ISO 3166-1 Alpha-2 国家码匹配规则。部署时应确保应用只能通过 Cloudflare 访问，避免客户端绕过代理伪造该请求头。

## 可视化配置

管理员进入“系统设置 → 集成 → 网页分组地区访问”，可以为每个国家码配置：

- 允许在网页中选择的分组；
- 允许分组通过系统分组列表下拉多选，不能录入不存在的分组；
- API 密钥列表中已有但当前地区不可用的分组会保留并标记“此地区不可用”；
- 模型广场只展示至少包含一个当前地区可用分组的模型；
- 地区显示名称；
- 是否显示地区提示弹窗；
- 弹窗标题、正文、勾选文字、确认按钮和版本号。

只有当某地区配置的允许分组少于系统分组总数时，该地区才会被视为受限地区并显示弹窗。弹窗每次完整进入网页都会重新出现，确认状态不会持久化。

规则匹配时精确国家码优先，其次回退到 `*` 通配规则。只有在既没有精确规则、也没有 `*` 规则时，未配置地区才不受网页分组限制。地区规则为空时不会影响 API 调用。
